見たい作品を起点に、**前史（incoming）** と **後続（outgoing）** を有向にたどれる、非公式・非商用のインタラクティブ相関図です。

## 特徴

- 131作品 / **199の有向接続**
- 日本公式邦題を主表示
- 作品をクリックすると、前史・後続・直接補助を即時ハイライト
- **クリックしてもチャートの位置・倍率は自動変更しない**（必要なときだけ「選択へ」を使用）
- `関連全体 / 1段階 / 2段階`
- 複数選択の `OR / AND / PATH`
- 接続重要度 `中核 / 推奨 / 参照`
- 「この作品を見るなら？」視聴目標と `最低限 / おすすめ / 完全版` の予習プラン
- **全131作品の視聴進捗率、視聴済みチェック、未視聴分の残り時間、1日2時間ペースの目安**
- 視聴済み作品をチャート上で任意に消灯
- 系列フォーカス、検索、主要キャラクター絞り込み
- PC / スマートフォン対応
- **通常スクロールはページ移動 / Ctrl・⌘ + ホイールで図をズーム**。スマホは1本指でページ移動、2本指で図を操作
- 各チャート右上の **「↓ 予習・視聴プラン」** から視聴管理へ直接ジャンプ
- 外部ライブラリ不要の単一HTML構成

## 使い方

1. 図の作品をクリックするか、上部の検索欄から作品を探します。
2. 選択した作品より前の流れは **← 前史**、先の流れは **→ 後続** として点灯します。クリックだけでは図の位置や倍率は動きません。
3. 選択作品を画面中央へ寄せたい場合だけ、詳細設定の **「選択へ」** を押します。
4. チャート下の大きな **予習・視聴プラン** では、全131作品の視聴進捗と、時間登録済み作品の残り総時間を確認できます。
5. 見終わった作品は作品名横のチェックボックスで **視聴済み** にできます。チェックはブラウザの `localStorage` に保存されます。
6. **視聴済みを図で消灯** をONにすると、チェック済み作品をチャート上で薄くできます。
7. チャート上でも普通のホイールはページスクロールとして動きます。図を拡大縮小したいときだけ **Ctrl / ⌘ + ホイール** を使います。スマホでは1本指でページ移動、2本指で図を操作します。

## 『ニュー・ミュータント』の扱い

『ニュー・ミュータント』は **FoxのX-MEN系列内の作品として同じタブ・系列に配置**していますが、現在のチャートでは他作品への直接矢印を置いていません。

Essex Corp. や『LOGAN／ローガン』の映像を想起させる要素はありますが、このチャートの矢印は「同じユニバース／ブランドである」こと自体ではなく、**視聴順や物語のつながりとして線を引く価値がある具体的な接続**を表す方針です。そのため、これらは直接矢印には採用しない判断に戻しました。

## 全体進捗・視聴済みチェックと残り時間

チャート下の「予習・視聴プラン」エリア上部に全131作品の視聴進捗カードがあります。視聴済み作品数・進捗率に加え、時間データ登録済みの未視聴作品を全部見るための残り総時間を表示します。時間未登録作品は推測せず、未登録件数として別表示します。

- 未視聴作品だけを合計した **残り視聴時間** を表示します。
- 「予習を全部チェック」「この予習だけチェック解除」で現在のプランをまとめて操作できます。
- 視聴目標そのものにもチェックを付けられます。
- 「視聴済みを図で消灯」はON/OFFでき、設定もブラウザに保存されます。
- チェック済み作品が別の予習プランに現れた場合も視聴済みとして扱います。
- チェック時は現在見ている行のスクロール位置を保持します。

## 視聴時間について

視聴時間は**厳密な計時データではなく、計画を立てるための目安**です。

- 映画は標準的な劇場版・配信版の上映時間を使用しています。
- シリーズは原則として、そのシーズンを全話見る場合の時間です。
- 配信版、特別版、クレジットの扱いなどにより差が出ることがあります。
- 未公開作はランタイムが確定するまで推測値を入れません。
- 時間データが未登録の作品は、登録済み分だけを合計し未登録件数を表示します。

## GitHub Pages で公開する

このフォルダの中身をリポジトリ直下に置けば、そのまま静的サイトとして公開できます。

1. GitHub にリポジトリを作成し、このフォルダのファイルを `main` ブランチのルートへ置きます。
2. **Settings → Pages** を開きます。
3. **Build and deployment → Source** で **Deploy from a branch** を選択します。
4. Branch を `main`、Folder を `/(root)` にして保存します。
5. デプロイ完了後、Pages のURLへアクセスします。

GitHub公式ドキュメント: <https://docs.github.com/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site>
