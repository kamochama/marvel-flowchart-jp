# マーベル作品相関図 日本版

個人用に作成したマーベル映像作品の非公式・非商用インタラクティブ相関図の公開版です。
見たい作品をゴールに選び、前史・後続・予習ルートをたどれます。

## GitHub Pages で公開する

このフォルダの中身をリポジトリ直下に置けば、そのまま静的サイトとして公開できます。

1. GitHub にリポジトリを作成し、このフォルダのファイルを `main` ブランチのルートへ置きます。
2. **Settings → Pages** を開きます。
3. **Build and deployment → Source** で **Deploy from a branch** を選択します。
4. Branch を `main`、Folder を `/(root)` にして保存します。
5. デプロイ完了後、Pages のURLへアクセスします。

## バージョン

**PUBLIC v5.11.2 — 2026-08-23**

v5.11.1 のスマホ **Canvas + LOD** とカメラ挙動を維持しつつ、操作中の画質と軽さのバランスを調整しました。

- 全体表示〜低倍率での1本指パンは従来どおり **LOD 0.25**。軽さを優先します。
- 文字を読むために拡大した状態での1本指パンは **LOD 0.5**。線と文字の粗さを抑えます。
- 2本指ピンチ中は **LOD 0.25** のまま。最も重い操作の滑らかさを優先します。
- 指を離した後は従来どおり表示倍率に合うLODへ戻ります。
- 既存の0.25 / 0.5 / 1.0キャッシュを使い分けるだけなので、キャッシュ段数・常駐メモリは増やしていません。

常時LOD 0.5にする案も比較しましたが、全体表示で不要な負荷が増えたため採用せず、倍率連動方式にしています。

OR / AND / PATH 全8,515組、単一ゴール予習393パターン、Guardians VOLUME 3、複数ゴール、⑥独立表示、ニュー・ミュータント直接矢印0、PC/スマホ操作を v5.11.1 に対して回帰確認しています。
