# マーベル作品相関図 日本版

見たい作品を起点に、**前史（incoming）** と **後続（outgoing）** を有向にたどれる、非公式・非商用のインタラクティブ相関図です。

![サイトプレビュー](preview.png)

> **企画・実装・データ整理・文章・監査の多くに生成AI（主にChatGPT）を利用しています。** 人手でも確認・調整していますが、内容の完全性・正確性は保証しません。

## できること

- 131作品 / **199の有向接続**を相関図で表示
- 作品をクリック／タップするとゴールに追加し、前史・後続をハイライト
- `関連全体 / 1段階 / 2段階`
- 複数ゴールの `OR / AND / PATH` と、重複を除いた統合予習プラン
- `最低限 / おすすめ / 完全版` の予習プランと、ゴール自身を含む見る順
- 視聴済みチェック、進捗率、未視聴分の残り時間
- 視聴済み作品の任意消灯
- 日本公式邦題を優先表示
- PC / スマートフォン対応（スマホはフォーカス表示が標準）

## 使い方

1. 図上の見たい作品をクリック／タップしてゴールにします。複数選べます。
2. 前の流れは **← 前史**、先の流れは **→ 後続** として点灯します。
3. チャート下の **予習・視聴プラン** で、複数ゴールをまとめた見る順・所要時間・視聴済み状況を確認できます。
4. 視聴済みチェックはブラウザ内に保存されます。

通常のホイール / 1本指スワイプはページスクロールです。図のズームは **Ctrl / ⌘ + ホイール**、スマホでは2本指で操作できます。

## 注意

- 非公式・非商用のファン制作です。Marvel / Disney その他各権利者とは提携していません。
- 接続の `中核 / 推奨 / 参照` は、このサイト独自の視聴ガイド上の分類です。
- 同じシリーズ・ユニバースに属していても、視聴順や物語上の直接接続が弱い場合は矢印を置かないことがあります。
- 公開・配信情報や作品間の関係には誤り・更新漏れがあり得ます。
- 視聴時間は計画用の目安です。
