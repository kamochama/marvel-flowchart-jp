# マーベル作品相関図 日本版

個人用に作成したマーベル映像作品の非公式・非商用インタラクティブ相関図の公開版です。
見たい作品をゴールに選び、前史・後続・予習ルートをたどれます。

## GitHub Pages で公開する

このフォルダの中身をリポジトリ直下に置けば、そのまま静的サイトとして公開できます。

1. GitHub にリポジトリを作成し、このフォルダのファイルを `main` ブランチのルートへ置きます。
2. **Settings → Pages** を開きます。
3. **Build and deployment → Source** で **Deploy from a branch** を選択します。
4. Branch を `main`、Folder を `/(root)` にして保存します。
5. デプロイ完了後、Pages のURLへアクセスします。

## バージョン

**PUBLIC v5.10.19 — 2026-08-23**

v5.10.18 の機能・データを維持しつつ、Android / スマホの巨大SVG描画を軽くするための実験的な最適化を入れた版です。

- スマホでは巨大SVGへの常時 `will-change: transform` / `backface-visibility: hidden` を廃止。
- スマホのパン・ズームは `translate3d` ではなく2D `translate + scale` を使用。
- スマホの非選択ノード・非選択エッジは、grayscale / brightness / saturate のCSS filterを使わず opacity だけで消灯。
- 選択ゴールの赤／黄の強調は維持。
- PC側の3D transformと従来filter表示は変更なし。
- 合成ヘッドレスChromeの60フレームパンでは、最大の再描画レイヤー面積が **11,753,993 px → 1,129,440 px（約90.4%減、約10.4分の1）**。
- 上記は実スマホFPSそのものではないため、Android実機での体感確認を前提とします。

OR / AND / PATH 全8,515組、単一ゴール予習393パターン、Guardians VOLUME 3、複数ゴール、⑥独立表示、ニュー・ミュータント直接矢印0、PC操作を v5.10.18 に対して回帰確認しています。
