# マーベル作品相関図 日本版

MCU／Disney+／旧Marvel TV／X-MEN／Spider-Man系などの映像作品を、**「どこから来て、どこへ続くか」**でたどるためのインタラクティブ相関図です。

## 公開ページ

https://kamochama.github.io/marvel-flowchart-jp/

## 使い方

- 作品をクリックすると、その作品に関係する前史・後続が点灯します。
- 青系の線は前史、緑系の線は後続、オレンジは直接の補助接続です。
- 複数作品をゴールにして OR / AND / PATH 表示もできます。
- 「この作品を見るなら」では、ゴールまでの予習候補と残り視聴時間を確認できます。
- 視聴済みチェックはブラウザに保存されます。
- Shared Room では最大4人まで視聴済み状況を共有できます。
