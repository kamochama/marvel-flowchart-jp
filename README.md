# マーベル作品相関図 日本版

個人用に作成した、マーベル映像作品の非公式・非商用インタラクティブ相関図です。
見たい作品をゴールに選び、前史・後続や予習ルートをたどれます。

![サイトプレビュー](preview.png)

## 使い方

- 図の作品をタップすると、その作品をゴールに追加・解除できます。
- 選択した作品に関係する前史・後続が点灯します。
- 「予習・視聴プラン」で見る順番や視聴済み状況を確認できます。
- スマホでは1本指で移動、2本指でズームできます。
- PCではドラッグで移動、Ctrl / ⌘ + ホイールでズームできます。

## 予習プランを共有する

- **画像で共有** — 現在の予習プランをPNG画像にして共有できます。
- **一緒に見る** — 共有リンクから最大4人で入り、参加者ごとの視聴済みをほぼリアルタイムで共有できます。

通常利用の視聴済みチェックはこれまで通りブラウザ内に保存されます。共有ルームを利用したときだけ、表示名・共有プラン・共有用チェック状態を同期します。共有ルームは30日間利用がないと削除されます。

## GitHub Pages で公開する

このフォルダの中身をリポジトリ直下に置けば、そのまま公開できます。

1. GitHub にリポジトリを作成し、このフォルダのファイルを `main` ブランチのルートへ置きます。
2. **Settings → Pages** を開きます。
3. **Build and deployment → Source** で **Deploy from a branch** を選択します。
4. Branch を `main`、Folder を `/(root)` にして保存します。
