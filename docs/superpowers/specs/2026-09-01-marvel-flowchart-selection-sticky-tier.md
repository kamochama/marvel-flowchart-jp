# Marvel Flowchart Selection, Sticky Guide, and Shared Tier Specification

## Goal

作品の再クリック・空白クリックで選択を解除し、PCでは操作ガイドとビュータブを画面上部に固定する。チャートの「つながり」を予習プランと同じ3ティアで選べるようにし、全ての登録線は表示したまま、選択したティアの経路だけを点灯する。

## User-facing behavior

- 同じ作品をもう一度クリックすると、その作品のゴールだけを解除する。
- チャートの背景をクリックすると、全ゴールを解除する。
- ノード・線・ツールチップ・チャート内コントロールのクリックは空白クリック扱いにしない。
- ドラッグ／ピンチ終了時は、移動した事実をクリック解除処理より優先する。
- PCの「はじめかた」と5つのビュータブは、操作コントロールとは別の固定ナビ層として、ページを縦スクロールしても画面上端に残る。
- スマホは既存のモバイルナビとタッチ操作を維持し、ガイドとデスクトップ用タブを重複表示しない。
- チャートの「つながり」は `公式予習ルート`、`サイト提案ルート`、`完全版` の3択にする。
- チャートのティア選択は予習プランのティアと同期する。
- ティア変更はデータベースやエクスポートされたエッジを削除しない。未選択線は薄く表示し、対象経路だけを点灯する。
- `点灯範囲`（関連全体／1つ前のみ）と、3ティアは独立した設定として扱う。
- `importance` はエッジ固有のメタデータとして保持し、予習ティアの意味へ直接変換しない。

## Derived-state contract

チャートと予習プランは、同じ `buildMultiGoalPlan(goalIds, tier)` の結果を基礎にする。チャート選択状態は `prepTier`、ゴール、点灯範囲、複数ゴール条件から、以下を導出する。

- `tierNodeIds`: 選択ティアの前史ノードとゴール
- `tierBackEdges`: 公式／サイト提案の経路、または完全版の後方探索で点灯する前史線
- `tierForwardEdges`: 既存の後続表示（点灯範囲と有向探索）
- `tierContextEdges`: 直接補助線

公式予習ルートに登録がないゴールは、サイト提案へ暗黙にフォールバックせず、前史点灯なしとして扱う。複数ゴールはティア経路をunionする。完全版は既存の再帰的前史と直接参照の意味を維持する。

## Gesture contract

各チャートのビュー状態は、ポインタ開始時の対象・座標・移動済みフラグを保持する。背景の `pointerup` でのみ、移動量が閾値未満かつドラッグ／ピンチでない場合に `clearAllGoalsWithUndo` 相当の解除を行う。ノード選択の既存クリック経路と右クリックのゴール追加は維持する。

## Responsive layout contract

ガイドとタブは `<header>` の直後にある `.public-nav-sticky` に一つだけ置く。PCではこの層だけを `position: sticky; top: 0` で固定し、操作コントロールの高さ変化（詳細設定の開閉を含む）がチャートを覆わないようにする。スマホではラッパーごと非表示にし、`mobilePrimaryNav`だけを表示する。

## Verification

- 静的契約テストでDOM配置、3ティア同期、全線維持、importance非混同、解除・ドラッグガードを検査する。
- 既存の library-v5 全テストを実行する。
- bundled Pythonで `scripts.library_v5.build` を実行し、canonical CSV差分、監査、DB整合性を確認する。
- PCブラウザで縦スクロール固定、背景クリック解除、同一作品再クリック、ドラッグ後非解除を確認する。
- モバイル相当幅で既存ナビ、タップ選択、Canvas点灯が変わらないことを確認する。
